# Flower for Una 🌸

A handcrafted digital flower bouquet created as a heartfelt gift. Built with pure HTML, CSS, and JavaScript, this website features a fully illustrated SVG bouquet, soft animations, and an interactive greeting card experience—without using any frameworks or external image assets.

## Features

- Hand-drawn SVG flower bouquet
- Soft floating and blooming flower animations
- Interactive ribbon that reveals a personalized message
- Bouquet bloom effect when clicked
- Responsive design for desktop and mobile devices
- Respects the user's `prefers-reduced-motion` accessibility setting
- Lightweight and dependency-free

## Project Structure

```
flower-for-una/
├── index.html   # Main page and SVG bouquet
├── style.css    # Styling, colors, and animations
├── script.js    # Interactive behaviors
└── README.md
```

## Customization

You can easily personalize the website by:

- Editing the greeting message in `index.html`
- Changing the color palette in the `:root` variables inside `style.css`
- Replacing text with your own personal message
- Adding your own music, photos, or additional animations
